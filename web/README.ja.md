# PyxelBasic Web

[English](README.md) | 日本語

PyxelBasic をブラウザで動かすための一式です。Pyxel 公式の web ランタイム
の上で、デスクトップ版と同じソースコードの `pyxelbasic` パッケージをそのまま実行します。
インストール不要で、ページを開いて画面をクリックすればすぐに使えます。

> 公開ページ: https://takeshimaeda.github.io/PyxelBasic/

このページは、web 版を利用する人向けに操作とデスクトップ版との違いを説明します。

## ページの機能

- **Storage パネル** — BASIC の `SAVE` / `LOAD` / `FILES` はブラウザの
  ストレージ（IndexedDB）を使う。パネルから一覧・ダウンロード・削除・ドラッグ＆ドロップでの
  取り込み・URL からの取り込みができる。初回アクセス時にサンプルプログラムが
  自動で用意される。
- **ディスクイメージ** — Storage パネルの「Disk image」でストレージの全ファイルを
  1 つの ZIP に書き出し（Export）、ZIP を読み込んでストレージの内容を丸ごと
  入れ替えられる（Import・確認ダイアログあり）。フロッピーディスクや USB メモリの
  イメージファイルの感覚で、バックアップや別ブラウザへの持ち運びに使える。
  作られる ZIP は普通の ZIP なので OS 標準のツールでも開け、OS で作った ZIP
  （.bas をまとめたもの）の取り込みもできる。ドロップゾーンに `.zip` を落とした
  場合もイメージの取り込みになる。テーマなどのページ設定はイメージに含まれず、
  取り込みでも消えない。
- **Options パネル** — 起動時ロード・自動実行・steps per frame・FPS 表示を
  設定して「Apply and Restart」で再起動する。
- **Theme パネル** — 画面まわりの配色をプリセットまたは色ごとの上書きで変更でき、
  設定はブラウザに保存される。
- **クエリパラメータ** — URL で起動時の動作を指定できる:

| パラメータ | 意味 |
|---|---|
| `?load=NAME` | 起動時にストレージの NAME を読み込む |
| `&run=1` | 読み込んだプログラムを自動実行する |
| `&spf=N` | 1 フレームあたりの実行命令数（既定 8000） |
| `&fps=1` | フレームレートをタイトルに表示する |
| `&src=URL` | 起動前に URL のプログラムをストレージへ取り込む（`load=` 未指定ならそれを起動時ロードにする） |
| `&name=NAME` | `src=` の保存名（既定は URL のファイル名） |

共有リンクの例（開くだけでプログラムが走る）:

```
https://takeshimaeda.github.io/PyxelBasic/?src=https://raw.githubusercontent.com/.../game.bas&run=1
```

`src=` の取得元は CORS を許可しているホストに限られます
（raw.githubusercontent.com、gist、jsdelivr などは可）。

## デスクトップ版との違い

- 実行モードは main モード固定（ブラウザにスレッドがないため thread モードなし）
- `SAVE` / `LOAD` / `FILES` はブラウザストレージ（`--workdir` / `--ext` 相当なし、
  拡張子は `.bas,.pxbas` 固定、ファイル名は大文字小文字を区別）
- ESC の終了ダイアログで終了すると画面が止まったままになる（ページを
  リロードすると再起動する）
- プライベートブラウズなどブラウザストレージが使えない環境では、ストレージは
  メモリ上の一時的なものになる（ページに警告が表示される）
